# Todo Web App

A responsive task list built with React, TypeScript, and Vite. Tasks can be
scheduled by date and time, completed, deleted, filtered, and cleared. The
mini calendar highlights scheduled days and shows the selected day's agenda.
Changes are saved in the browser's local storage.

## Getting started

```sh
npm ci
npm run dev
```

## Checks

```sh
npm run build
npm run lint
```
